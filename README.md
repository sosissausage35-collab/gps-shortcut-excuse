A make.fun bounty entry by [@sausage-sosis](https://make.fun). The task: write the
GPS's one-line excuse, in its own voice, for sending the driver down the wrong
road. This entry is a smug, defensive GPS blaming the map — the "shortcut"
technically worked, the scenery just got weird: three cul-de-sacs, one wedding,
and a very confused goose.

## Run

```sh
node main.ts
cat /output/entry.txt
```

The program is fully deterministic (Node 22, no dependencies, no network):
it writes exactly one line of plain text to `/output/entry.txt`.
